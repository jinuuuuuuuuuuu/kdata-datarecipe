# kdata-datarecipe

2026 데이터 공모전(데이터 문제해결 부문, 데이터레시피 제안) 팀 저장소입니다. 전국 256개 시군구(2026년 행정구역)가 1GW급 AI 데이터센터를 수용할 수 있는지 5개 피처로 진단합니다.

이 저장소에는 **출처와 처리 과정을 확인한 데이터셋만** 올렸습니다. 수자원, 냉각, 신재생 피처의 원천 데이터·코드·결과와 재해 피처의 홍수 결측 후처리가 포함됩니다. 전력과 재해 원천 데이터는 각 담당 팀원이 올릴 예정입니다.

## 피처별 포함 현황

| 피처 | 이 저장소에 있는 것 | 비고 |
|---|---|---|
| 수자원 | 원천 데이터, 코드, 결과 | 점수 열 `수자원_H` |
| 냉각 | 원천 데이터(기상청 시간자료), 수집·처리 코드, 결과 | 점수 열 `냉각_WSE가능비율` |
| 신재생 | 원천 데이터, 코드, 결과 | 점수 열 `신재생_점수` |
| 재해 | 홍수지도 미확보 지역 후처리 코드와 근거 자료, 결과 | 입력 `07_재해_점수화_최종.csv`와 그 원천 데이터는 **재해 담당 팀원 업로드 예정** |
| 전력 | 없음 | **전력 담당 팀원 업로드 예정** |

## 폴더 구성

```
data/
  raw/                원천 데이터(받은 그대로, 기상청 시간자료만 gzip 압축)
    reference/        시군구 기준표, 법정동코드
    water/            상수도통계, 국가수도기본계획 고시문
    cooling/          기상청 ASOS·AWS 시간자료(asos/, aws/), 관측지점 메타(meta/)
    renewable/        신재생 발전량, 발전사업 허가정보, 한전 PPA, 풍력기 위치, 시 자체 자료
    disaster/         전라남도 지방하천 현황(홍수 결측 처리 근거)
  processed/          결과 데이터
    수자원_냉각_통합.csv   수자원·냉각 통합(256행 × 58열)
    신재생_피처.csv        신재생 피처(256행)
    재해_피처.csv          재해 피처(256행, 홍수 결측 처리 반영)
    water/, cooling/      피처별 단독 결과와 검증 파일
src/                  처리 코드(경로는 모두 저장소 기준 상대경로)
docs/                 컬럼 설명서, 물 수요 기준값 근거, 냉각·수자원 사용 계획
```

모든 파일은 `시군구코드`(5자리 문자열, 2026년 행정구역)로 연결합니다. 읽을 때 `dtype={'시군구코드': str}`, 인코딩은 `utf-8-sig`를 쓰세요. 이름으로 병합하면 안 됩니다(서구·동구·고성군 등 중복).

## 피처 요약

- **수자원** `수자원_H`(m³/일): 최대급수일 기준 공급 여유. `H = max(자체 정수장 여유, 0) + 연결된 K-water 광역 정수장 여유 + 이웃에서 받는 정수`. 점수는 `log(1+H)` min-max 정규화. 탈락 기준 D = 4,080 m³/일(1GW × 24h × 공랭 WUE 0.17 L/kWh)은 점수가 아니라 구분에만 씁니다(`수자원_탈락여부`, 44행). 근거는 `docs/기준값D_근거.md`.
- **냉각** `냉각_WSE가능비율`: 습구온도 12.8℃ 이하 시간 비율(2024~2025 평균, 습구온도는 Stull 2011 식). 점수는 min-max 정규화. `냉각_여름극값비율`은 참고 열.
- **신재생** `신재생_점수`: 재생에너지 발전량(MWh)의 `log(1+x)` min-max 정규화(범위는 KEA 원자료가 직접 대응되는 213행 기준). 원자료가 시 단위인 13개 시의 39개 구와 인천 신설구 4개(총 43행)는 허가정보 설비용량 비율과 대형 발전소 소재지로 배분한 추정값이며 `신재생_추정`, `신재생_배분_신뢰도`(높음/중간/낮음/매우 낮음)로 표시합니다. 대체 비율로 나눈 값은 `신재생_발전량_대체배분_MWh`.
- **재해** `재해_안전도` = 1 − 재해위험지수. 위험지수 = (0.19×지진 + 0.17×홍수 + 0.13×산사태 + 0.08×산불)/0.57, 연안 CO Yellow는 ×1.2, CO Red 10곳은 후보제외. 홍수지도가 없는 6곳 중 국가·지방하천이 없는 곳은 홍수 0, 하천은 있으나 지도가 없는 신안군은 홍수 점수 25분위로 대체하고 `재해_홍수대체`로 표시합니다.

열 정의는 `docs/컬럼_설명서.md`(수자원·냉각)와 각 결과 파일의 열 이름을 참고하세요.

## 재현 방법

Python 3.12, pandas 3.0, numpy 2.5, openpyxl 3.1에서 확인했습니다.

```bash
pip install -r requirements.txt
python src/water/build_water_feature.py          # -> data/processed/water/
python src/cooling/build_cooling_feature.py      # -> data/processed/cooling/ (약 2분)
python src/merge_features.py                     # -> data/processed/수자원_냉각_통합.csv
python src/renewable/build_renewable_feature.py  # -> data/processed/신재생_피처.csv
python src/disaster/build_disaster_feature.py    # 입력: data/raw/disaster/07_재해_점수화_최종.csv (재해 담당 업로드 후)
```

기상청 시간자료를 처음부터 다시 받으려면 `src/cooling/.env`에 `KMA_AUTH_KEY=발급키`를 넣고 `collect_hourly.py`, `collect_hourly_aws.py`, `refill_failed_aws.py`를 실행합니다. 받은 월별 CSV는 그대로 써도 되고(코드가 `.csv`와 `.csv.gz`를 모두 읽음), 저장소에는 용량 때문에 gzip으로 압축해 올렸습니다. `.env`는 올리지 마세요.

## 최종 검수 (2026-10-08)

- 저장소의 원천 데이터와 코드만으로 위 순서를 다시 실행해, 결과 파일 7개가 작업용 최종본과 **바이트 단위로 동일**함을 확인했습니다.
- 결과 5개 파일 모두 256행이며 `시군구코드`가 유일하고, 기준표의 코드 집합·시군구명과 일치합니다.
- 수자원: `수자원_H` 결측·음수 0, H=0 26행, 탈락(H < 4,080) 44행. 로그 정규화 점수에서 H<D 최고 0.588, H≥D 최저 0.590으로 점수와 탈락 판정의 순서가 어긋나지 않습니다.
- 냉각: `냉각_WSE가능비율` 0.407~0.619, 결측 0. 품질플래그 정상 246행, 나머지 10행은 커버리지 낮음·기준 완화·고지대 표시.
- 신재생: 점수 결측 0(0~1), 배분 추정 43행. 배분한 구의 합은 모든 시에서 원래 시(구) 합계와 같습니다(에너지원별 반올림 차이 5MWh 이내).
- 재해: `재해_안전도` 결측 10행 = 연안 CO Red 후보제외 10행. 홍수 원값이 있는 행은 입력 파일의 최종 지수를 1e-5 이내로 재현합니다.
- 기상청 API 키 등 비밀값이 저장소 파일(압축 파일 포함)에 없음을 확인했습니다.

## 알려진 한계

- 전국 태양광 허가 표준데이터는 포털 다운로드가 5만 행으로 제한되어 전국 총량(약 21만 개소)보다 적습니다. 구별 비율에만 쓰고 총량에는 쓰지 않습니다.
- 한전 PPA는 태양광만 값이 있고, 계약 5건 미만 지역은 가려져 있습니다(2건 × 평균 계약용량으로 보정).
- 수자원 `H`는 같은 광역 정수장을 쓰는 지역끼리 여유를 중복으로 세는 낙관적 상한입니다. 보수적 비교는 `수자원_H_자체만`을 쓰세요.
- 냉각은 2년 평균이라 기후 평년값이 아니며, 관측소 1곳이 지역을 대표합니다.
- 인천 서구의 바이오 발전량(수도권매립지 매립가스)은 소재 법정동이 검단구·서해구에 걸쳐 귀속이 불확실합니다. 반대로 귀속한 값은 `신재생_발전량_대형발전소반대귀속_MWh`에 있습니다.
