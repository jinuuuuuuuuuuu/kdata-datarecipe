# 냉각·수자원 피처 사용 계획 (팀원 공유용)

작성 2026-10-07. 냉각과 수자원은 **서로 독립된 두 피처**로 씁니다. 하나로 합치지 않습니다.

## 2. 수자원 피처

**쓰는 열: `수자원_H`** (최대급수일에 이 지역이 더 댈 수 있는 물의 양, m³/일)

```
H = max(자체 정수장 여유, 0) + 연결된 K-water 광역 정수장 여유 + 이웃에서 받는 정수
정수장 여유 = 설계용량 − 최대급수일 생산량   (2024년 상수도통계)
```

**피처 계산: 로그 변환 후 min-max 정규화**

```
수자원 점수 = (log(1+H) − min) / (max − min)      → 0~1, 클수록 유리
```

```python
import numpy as np, pandas as pd
df = pd.read_csv('수자원_냉각_통합.csv', encoding='utf-8-sig', dtype={'시군구코드': str})
x = np.log1p(df['수자원_H'])
df['수자원_점수'] = (x - x.min()) / (x.max() - x.min())
```

- **로그를 쓰는 이유:** H는 중앙값 약 7만, 최댓값 약 136만 m³/일로 크게 치우쳐 있습니다. 그대로 정규화하면 상위 몇 곳이 점수를 독차지합니다.
- **log(1+H)를 쓰는 이유:** H=0인 26행에서 log(0)이 정의되지 않기 때문입니다. 이 행들은 점수 0이 됩니다.
- **결과 분포:** 중앙값 0.79, 25분위 0.66, 75분위 0.90, 10분위 0.10.

**이전 방식은 쓰지 않습니다.** `수자원_Water_final`, `S_cov`, `S_stress`(0.7/0.3 가중)는 계수가 임의였고, S_cov는 통과 지역 172행이 상한(1.0)에 닿아 변별력이 없었습니다. 파일에는 참고 열로 남아 있습니다.

**등급 기준: D = 4,080 m³/일** (1GW × 24시간 × 공랭 WUE 0.17 L/kWh)
- `수자원_탈락여부` = H < D (44행). D는 **점수에는 들어가지 않고 등급·탈락 구분에만** 씁니다.
- 로그 정규화 점수에서 H<D인 행은 최고 0.588, H≥D인 행은 최저 0.590이라 **점수 약 0.59가 D 경계**와 정확히 일치합니다. 순서가 바뀌지 않아 점수와 탈락 판정이 서로 모순되지 않습니다.
- [H<D 44행을 순위에서 제외할지, 최하위 등급으로 둘지: 팀 결정]

## 3. 냉각 피처 (확정: 단일 피처)

**쓰는 열: `냉각_WSE가능비율`** (습구온도 ≤ 12.8℃인 시간 비율 = 외기만으로 식힐 수 있는 시간, 0.41~0.62, **클수록 유리**)

```
냉각 점수 = (WSE가능비율 − min) / (max − min)      → 0~1, 클수록 유리
```

- 기상청 ASOS·AWS 2024~2025년 시간별 기온·습도, 습구온도는 Stull(2011) 식, 두 해 평균입니다. 비율 지표라 분포가 치우치지 않아 로그 없이 min-max 정규화합니다.
- **WSE를 고른 이유:** 연 8,760시간 전체의 냉각 부담을 재서 운영 전력(PUE)과 직접 연결됩니다. 여름극값(6~8월 2,208시간)은 설계 첨두 부담이라 성격이 다릅니다.
- **여름극값은 점수에 쓰지 않습니다.** 두 지표의 상관이 0.63(극값을 반전한 값 기준)이라 WSE에 이미 상당 부분 반영되어 있고, WSE 상위권과 여름극값 상위 25%가 겹치는 지역은 0곳입니다. 50:50 합성과의 순위 상관은 WSE 단일 0.85, 극값 단일 0.92로 단일 지표로도 합성과 큰 틀이 같습니다.
- `냉각_여름극값비율`은 **진단용 참고 열**로 남깁니다(등급 보강 항목 설명에서 "폭염 부담" 언급 시 사용).
- **정규화 모집단:** 최종 순위 계산에서는 5개 피처 모두 순위 대상 행(후보제외 행 제외)에서 다시 min-max합니다. 제주(WSE 0.00~0.15)가 후보제외라 모집단 최솟값이 달라집니다.
- 냉각 가중치(9.68%)가 가장 작아 유효 영향도는 약 6%입니다.

## 4. 쓸 때 주의할 점

- **동률이 많습니다.** 같은 정수장을 쓰는 지역은 H가 같아 수자원 점수도 같습니다(고유값 112종/256행). 서울 25개 구는 모두 최고점입니다. 순위를 매길 때 같은 시의 구가 함께 상위에 몰릴 수 있습니다.
- **H는 낙관적 상한입니다.** 같은 광역 정수장을 쓰는 지역이 여유를 중복으로 셉니다. 한 곳에만 짓는 평가라면 문제없지만, 보수적으로 보려면 `수자원_H_자체만`을 같은 방식으로 정규화해 비교하세요.
- **냉각 품질 표시:** `냉각_품질플래그`가 `정상`이 아닌 10행(커버리지 낮음 등)은 해석할 때 주의하세요.
- **값 공유:** 시 단위 자료를 구가 같이 쓰는 행이 있습니다(`수자원_상위시값공유` 117행, `냉각_상위시값공유` 24행).
- **결측:** 냉각·수자원 점수에 쓰는 열(`수자원_H`, `냉각_WSE가능비율`, `냉각_여름극값비율`)은 256행 모두 값이 있습니다.
