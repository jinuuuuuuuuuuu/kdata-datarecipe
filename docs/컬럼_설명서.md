# 컬럼 설명서: 수자원_냉각_통합.csv (256행 × 58열)

접두사 `수자원_`은 수자원 피처, `냉각_`은 냉각 피처에서 온 컬럼이다. 식별 컬럼 4개에는 접두사가 없다.
"0/결측 의미" 열은 0 또는 빈 값이 실제 측정값인지, 채워 넣은 값인지를 적었다.

## 식별
| 컬럼 | 설명 | 형식 |
|---|---|---|
| 시군구코드 | 병합 키. 5자리 행정 시군구 코드 | 문자열 |
| 개편전코드 | 2023년 이후 개편 전 코드. 신설 구는 빈 값 | 문자열 |
| 시도 | 시도(광주+전남은 "전남광주") | 문자열 |
| 시군구 | 시군구 이름(구가 있는 시는 "수원시 장안구") | 문자열 |

## 수자원
물 수요 기준값 **D = 4,080 m³/일**(1GW × 24h × 공랭 WUE 0.17 L/kWh, 정부 AIDC 메가프로젝트 부지 단위 0.5~1GW 기준, 첨두계수 미적용)로 탈락·점수를 계산했다. 근거는 `기준값D_근거.md`. 다른 D로 다시 계산하려면 `apply_water_gate.py`를 쓴다.

|---|---|---|---|

| 수자원_산출근거 | H를 이루는 공급원 조합(자체/광역/정수수입) | 문자열 | 미매칭 행은 없음 |

| 수자원_공유정수장_사업자수 | 연결된 K-water 정수장 중 가장 많이 공유되는 정수장을 쓰는 사업자 수(자기 포함). 클수록 같은 여유를 여럿이 공유 | 정수 | 0이면 K-water 광역 연결 없음 |

| 수자원_S_stress | (참고용, 최종 점수에 쓰지 않음) 여유 부족 스트레스 점수 = clip((1−U)/0.3, 0~1) | 0~1 | **0은 U ≥ 1(설계용량 이상으로 가동, 43행). 0.5는 U가 비어서 넣은 중립값(38행)** |

| 수자원_D_기준 | 탈락 판정에 쓴 물 수요 기준값(모든 행 4,080) | m³/일 | |
| 수자원_S_cov | (참고용, 최종 점수에 쓰지 않음) 수요 충족 점수 = log1p(min(H/D, 5)) / log1p(5) | 0~1 | 0은 H=0. **1은 H가 D의 5배 이상(상한, 172행)** |

| 수자원_탈락여부 | H < D(4,080)이면 True(44행) | True/False | |
| 수자원_탈락여부_자체만 | H_자체만 < D이면 True(119행). 광역·수입 물 없이 본 보수적 판정 | True/False | |
| 수자원_광역협의필요 | H로는 통과하지만 자체 정수장만으로는 탈락(75행). 광역 공급 협의에 달린 지역 | True/False | |
