# 최종 순위 분석 과정과 결과

작성 2026-10-08. 5개 피처(전력·신재생·수자원·재해·냉각)를 결합해 256개 시군구의 AI 데이터센터(1GW급) 수용 점수, 등급, 보강 항목을 산출한 과정입니다. 코드는 `src/ranking/build_ranking.py`, 결과는 `data/processed/최종_순위.csv`(256행 × 34열), 실행 로그는 `docs/최종순위_실행요약.txt`입니다.

## 1. 입력

| 피처 | 파일 | 점수에 쓰는 열 | 방향 |
|---|---|---|---|
| 전력 | `data/raw/power/전력_최종피쳐_공유용_v4_20261006.csv`(전력 담당 팀원 업로드 예정) | `전력피쳐`(변전소 여유 MW 2029 / 895) | 클수록 유리 |
| 신재생 | `data/processed/신재생_피처.csv` | `신재생_발전량_MWh` → log(1+x) | 클수록 유리 |
| 수자원 | `data/processed/수자원_냉각_통합.csv` | `수자원_H` → log(1+H) | 클수록 유리 |
| 재해 | `data/processed/재해_피처.csv` | `재해_안전도` = 1 − 위험지수 | 클수록 유리 |
| 냉각 | `data/processed/수자원_냉각_통합.csv` | `냉각_WSE가능비율` | 클수록 유리 |

모두 `시군구코드`(5자리 문자열)로 1:1 병합했고 256행이 그대로 유지됩니다.

## 2. 절차

1. **후보제외 11곳:** 전력 분석 제외(울릉군) 1곳과 연안 고위험(CO Red) 10곳은 점수를 매기지 않습니다.
2. **재정규화:** 후보제외를 뺀 245곳 안에서 피처마다 min-max로 0~1로 다시 맞춥니다. 신재생은 한국에너지공단 원자료가 직접 대응되는 행에서 범위를 잡고 배분 추정치는 0~1로 자릅니다. 피처마다 분포가 달라 이 단계 없이 가중치만 곱하면 실제 영향이 명목 가중치와 달라지기 때문입니다.
3. **가중합:** 논문(이기수·정준호, 2026, Fuzzy-AHP 입지요인 중요도)의 AHP 종합중요도를 5개 피처에 맞춰 비율을 다시 맞춘 값을 씁니다.
4. **결측 처리(방법 A):** 결측 피처가 있으면 남은 피처로 가중치를 다시 나눕니다. 다만 이 점수는 부풀 수 있어 등급을 매기지 않고 **판정보류**로 둡니다(전력 결측 3곳).
5. **등급:** 용수선결(H < D = 4,080 m³/일) → 나머지에서 A 상위 20%, B 20~50%, C 하위 50%.
6. **보강 항목·강점:** 전력 여유 0MW, 용수 부족(H < D), 그 밖에 평가 대상 하위 25% 피처를 보강 항목으로, 상위 25% 피처를 강점으로 표시합니다.

## 3. 가중치

논문 표 5·6의 AHP 종합중요도에서 가져온 값입니다. 논문의 중분류와 이 과제 피처의 대응은 다음과 같습니다.

| 피처 | 논문 요인 | AHP 종합중요도 | 비율 |
|---|---|---|---|
| 전력 | 전력계통 연계성 | 0.2420 | **41.75%** |
| 신재생 | 환경 지속가능성 | 0.1114 | **19.22%** |
| 수자원 | 냉각환경 적합성 중 용수공급 안정성 0.0528 + 수자원 부담도 0.0422 | 0.0950 | **16.39%** |
| 재해 | 입지 안정성 | 0.0752 | **12.97%** |
| 냉각 | 냉각환경 적합성 중 냉각자원 확보성 0.0282 + 고밀도 냉각 확장성 0.0279 | 0.0561 | **9.68%** |

- 논문의 네트워크 연결성·부지 활용성·거버넌스 항목에 해당하는 피처는 이 과제 범위에 없어, 5개 피처 안에서 비율을 다시 맞췄습니다.
- 신재생↔환경 지속가능성, 재해↔입지 안정성은 일대일 대응이 아닙니다(논문의 환경 지속가능성은 저탄소 전력접근성·자원효율·물열환경을 포함하고, 입지 안정성은 재난복구·물리보안·인적재해까지 포함).
- 실제 순위에 미치는 영향은 피처 분포에 따라 달라, 표준편차로 가늠하면 전력 43.0%, 수자원 19.6%, 신재생 17.9%, 재해 11.7%, 냉각 7.8%입니다.

## 6. 한계

- **부지 조건 부재:** 1GW에 필요한 약 30만 평 부지를 반영하는 피처가 없어, 서울 도봉구·대구 동구·대전 서구 같은 도심 구가 상위(A)에 들어갑니다. 도심 구는 사실상 후보에서 빠진다는 점을 감안해 읽어야 합니다.
- **전력 변별력:** 평가 대상의 3분의 1 이상(86곳)이 변전소 여유 0MW로 같은 점수입니다. 전력 점수가 0인 지역끼리는 다른 피처가 순위를 가릅니다.
- **섬 지역:** 신안군은 1위지만 전력 여유(895MW)와 신재생 때문이며, 부지·실제 계통 접속은 반영하지 못했습니다.
- **추정값:** 신재생 43행은 배분 추정, 재해 홍수 6행은 대체값, 전력 6곳은 결측입니다. `해석주의` 열에 표시했습니다.
- **수자원:** `수자원_H`는 낙관적 상한입니다. 같은 광역 정수장을 쓰는 지역이 여유를 중복으로 셉니다.
- **확정 판정이 아닌 사전 진단:** 한전과의 실제 접속 협의, 관로 용량, 취수 권리는 공개 자료로 알 수 없어 반영하지 못했습니다.
- 가중치는 전문가 28명의 응답에 기반한 논문 값이며, 전력이 크게 좌우하므로 가중치를 바꾸면 순위가 달라집니다(동일 가중치에서는 상위 20곳 중 12곳만 겹칩니다).
